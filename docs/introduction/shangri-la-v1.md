# Shangri La v1

The current release of Gnosis VPN is **Shangri La**, version 1.0. It runs a decentralized VPN architecture on the HOPR mixnet and replaces all earlier releases.

## What Shangri La supports

- A functional VPN client
- HOPR-based routing
- End-to-end encrypted tunnelling
- Exit nodes discovered at runtime, with multiple locations
- On-chain metered payments
- macOS
- Linux (Debian, Ubuntu)

## What Shangri La does not support yet

:::info
Shangri La does not yet support Windows, Linux distributions other than Debian and Ubuntu, or mobile.
:::

## Earlier releases

Releases up to 0.97.1 run on networks that shut down on **21 November 2026**, and stop working then. Upgrade to Shangri La before that date, as described in [Managing the client](../get-started/managing-the-client.md).
